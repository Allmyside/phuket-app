# Структура проекта

Статический сайт для GitHub Pages, без сборки. index.html содержит разметку и внешние SDK; css/styles.css — исходные стили.

Скрипты подключены обычными defer script в следующем порядке. Они разделяют глобальную область: объявления функций доступны обработчикам HTML через window, а общие let/const — через глобальные имена (как в монолите). app.js запускается последним.

- js/config.js — исходные строки 1912–1985, 5526–5548, 5925–5938, 6545–6642
- js/utils.js — исходные строки 1737–1911, 3125–3195
- js/sync.js — исходные строки 1986–2863
- js/chat-users.js — исходные строки 2864–3123
- js/auth-admin.js — исходные строки 3196–3771
- js/calendar.js — исходные строки 3772–4382, 5340–5525
- js/checklist.js — исходные строки 4383–5117
- js/budget-exchange.js — исходные строки 5118–5339, 6227–6544, 6643–6832
- js/tides-weather.js — исходные строки 5549–5924, 5939–6225
- js/app.js — исходные строки 6833–7033

config — настройки и справочники; utils — форматирование, тема, аватарки и GPS; sync — синхронизация и присутствие; chat-users — пользователи и чат; auth-admin — авторизация и профили; calendar — вкладки, события и отпуск; checklist — вещи и дедлайны; budget-exchange — бюджет и курсы; tides-weather — приливы и погода; app — обновление и запуск.

sw.js — извлечённый Service Worker, список кэша дополнен файлами CSS/JS и манифестом. manifest.webmanifest — исходный объект манифеста вместо Blob URL. Относительные пути поддерживают размещение в подпапке GitHub Pages.
